Payroll ETL Pipeline

Three clients send timesheets in three different formats: a clean CSV, a messy spreadsheet export and an API JSON feed. This pipeline extracts all three, quarantines bad rows with a reason, applies shift penalty rates and weekly overtime, and loads a star-schema warehouse that payroll and Power BI read from. Every number below comes from the pipeline's own output.
